# claude local check for safe use

本地运行的浏览器环境检测工具，可直接启动，也可安装为 Codex Skill。无广告、无统计，结果不上传。WebRTC 默认开启，点击检测后会连接 Google 公共 STUN；IP 地区查询默认开启，随开始检测自动查询并计分，可手动关闭；完全离线检测需关闭 WebRTC 和 IP 查询两项。

## 如何使用

1. 从 [v1.1.0 发布页](https://github.com/l2461090/claude-local-check-for-safe-use/releases/tag/v1.1.0) 下载 `claude-local-check-v1.1.0.zip`。
2. 解压完整文件夹。需要 **Python 3.8+** 和现代桌面浏览器，无需 API Key、账号、Node.js 或第三方 Python 包。
3. 按系统运行启动文件：

| 系统 | 启动文件 |
| --- | --- |
| macOS | `launch-mac.command` |
| Windows | `launch-windows.cmd` |
| Linux | `launch-linux.sh` |

如果系统未直接运行文件，可在解压目录的终端执行：

```bash
python3 scripts/local_check.py start --open
```

Windows 可用 `py -3 scripts/local_check.py start --open`。若缺少 Python，可安装 Python 3.8+，或让本地 AI 助手寻找宿主自带的 Python。

打开网页后点击一次「开始检测」，会自动完成本地项目及 IP 与环境一致性查询并显示综合评分，无需单独开启或点击 IP 查询。检测的是当前打开页面的浏览器；平时在哪个浏览器使用 Claude，就将输出地址粘贴到那个浏览器。

每台电脑需要运行自己的副本。服务仅监听本机 `127.0.0.1`；默认尝试端口 4321，冲突时自动选择可用端口，以启动命令输出为准。

## IP 与环境一致性

新增模块已融合进100分总分。IP相关项目共49分，其余项目共51分；不重复累加原来的时区/语言/区域得分。联网开关默认开启；打开网页时不立即查询，点击“开始检测”自动查询并融合评分，也可点击“查询 IP 并比对”单独重查，浏览器直接访问 `https://ipapi.co/json/`。服务接收公网出口IP和常规请求头（例如UA/语言），不接收本页分数、字体、账号或系统时区。不通过Python服务代查。

显示IP推定国家/地区、时区、浏览器时区及当前UTC偏移，比较同名时区、同偏移但不同名、时差不同。按同一时刻计算，考虑夏令时和时区别名。语言按IP资料库的常用语言列表比较（主语言相同即匹配），区域格式按显式区域代码比较。按本工具规则，不一致即计对应项目权重；这不证明违规或真实封号概率。国家有多个时区、GeoIP误差、代理分流都可能造成差异。

查询失败、超时、限流或关闭时IP相关49分显示“未检测”，总分显示已测部分与可能区间，不显示完整低风险评级；关闭开关取消请求并清除结果，刷新后恢复为默认开启，仍需开始检测才发起请求。IP部分隐藏，导出图片只包含比对摘要；结果不写入服务日志或持久存储。只允许访问上述一个查询源，不自动切换其他第三方。此查询源可能有配额、CORS或服务可用性限制，接口说明见 [ipapi.co 文档](https://ipapi.co/api/)。

## 评级规则

| 完整分数 | 评级 | 结论文案 |
| --- | --- | --- |
| 0–30 | 低风险 | 环境风险较低 |
| 31–60 | 中等风险 | 环境存在风险信号 |
| 61–100 | 高风险 | 环境风险较高 |

检测完成后，结果卡先汇总“命中的信号”，按检测顺序展示匹配程度达到 25% 的项目名称和分值；保存的结果图片也包含同样的汇总。匹配程度低于 25% 的项目可能仍贡献少量分数，但不进入命中标签；全部计分可在明细中查看。

未检测项会标记，并列出可能的完整分数范围。存在未检测项时暂不提供完整评级；全部项目无法检测时显示“未获取到有效检测结果”。

这是一套浏览器特征与IP一致性的启发式评分，不代表 Claude 官方判断、账号使用资格或封号概率。本项目与 Anthropic 无隶属关系。

## 检测项目

| 项目 | 权重 | 本版规则 |
| --- | --- | --- |
| 时区与 IP 一致性 | 24 | IANA别名规范化后不同时区加24；同偏移但不同名仍加24；资料不足为未检测 |
| 首选语言与 IP 一致性 | 18 | 首选主语言不在IP地区常用语言列表加18；列表缺失为未检测 |
| 中文字体 | 14 | 72px Canvas 字宽差大于 0.5；简体字体匹配程度 min(1, 0.75 + 0.08 × 数量)，仅繁体为 0.2 |
| 厂商字体 | 10 | 命中一种匹配程度 0.8，两种及以上为 1 |
| WebRTC IP 泄露 | 10 | 默认开启，观察 1 秒；发现候选 IP 匹配程度 0.5（+5），否则 0 |
| 浏览器标识 | 8 | 结合 User-Agent 和 UA-CH brands 按优先顺序匹配 |
| 设备标识 | 6 | 结合 User-Agent 与 UA-CH 高熵型号/平台提示；厂商匹配程度 0.5–1 |
| 区域格式与 IP 一致性 | 4 | Intl格式区域代码不等于IP国家代码加4；无显式区域代码为未检测 |
| UTC 时差与 IP 一致性 | 3 | 按同一时刻计算两端时差，偏移不同加3，考虑夏令时 |
| Emoji 渲染风格 | 3 | 由 UA 和 platform 推断；Apple 0.25、Microsoft 0.4、Google 0.35、Linux 0.5、未知 0.4 |

非 IP 比对项目沿用兼容计分模式，本地检测异常或 WebRTC 超时未收到候选地址按 0 分计；界面会说明可识别的失败情况，0 分不证明不存在风险。WebRTC 受网络延迟、扩展、站点权限和浏览器策略影响，同一浏览器不同站点或不同时刻仍可能返回不同候选地址。

各项目匹配程度为 0–1，乘以权重后逐项四舍五入相加。评分与检测源码位于 `assets/site/model.js`、`assets/site/consistency.js`、`assets/site/checks.js` 和 `assets/site/rules.js`。

语言、字体和 UTC+8 也存在于其他地区，浏览器可能隐藏或改变标识，字体探测也可能误判，因此分数不能确定用户所在地。WebRTC 只反映地址暴露，不识别 IP 所属国家。

## 隐私与运行

- 结果只保留在浏览器内存中；刷新页面即清除。
- WebRTC 默认开启，点击检测才连接 Google 公共 STUN（stun.l.google.com:19302）。关闭该选项后不进行此网络通信，但总分是部分评分。IP地区查询是另一个独立开关，若要完全离线，两项都应关闭。
- 保存图片在本地 Canvas 中生成，由浏览器下载，无需上传。
- 不读取账号信息，不修改系统设置，不安装扩展。
- 启动器临时目录保存服务状态与错误日志，不保存检测结果。

```bash
python3 scripts/local_check.py status
python3 scripts/local_check.py stop
```

无法保持后台进程时，使用 `python3 scripts/local_check.py serve` 并保持终端开启。

## 开发与打包

页面使用可直接编辑的 HTML、CSS 和 JavaScript，无框架、无外部前端依赖、无需编译。`scripts/local_check.py` 使用 Python 标准库。主页面源码为 `assets/site/index.html`，打包时自动同步至 `/zh/` 入口。

修改后执行：

```bash
python3 scripts/package.py
python3 tests/test_launcher.py
```

打包脚本更新资源哈希，并在 `dist/` 生成 ZIP 和 SHA-256 校验文件。资源哈希检查用于发现损坏或安装不完整，不是数字签名。可选使用 Node.js 22+ 执行 `node --test tests/*.test.js` 验证评级逻辑。

已在 macOS 验证；提供 Windows 与 Linux 启动入口，尚未完成对应系统的手动实机验证。
